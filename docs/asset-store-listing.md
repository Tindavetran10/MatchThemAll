## Title
Match Them All: Match-3D Game Template

## Short description (one line)
A complete, ready-to-publish match-3D mobile game with a no-code level editor, power-ups, shop, daily rewards, and optional ads and in-app purchases.

## Long description
Match Them All is a finished match-3D game you can reskin, extend and publish. Players tap items from a pile into a tray at the bottom. Three of a kind merge, and the level is won when every goal card reaches zero before the timer runs out.

Everything is set up with buttons and fields in the Unity Editor, so you can make levels, items, sounds and power-ups without writing code.

**What's included**
- Complete game loop: Lobby, level map, gameplay, win and lose screens, stars and coin rewards
- 10 ready-made levels and 7 items
- 4 power-ups: Freeze Gun, Fan, Spring and Vacuum, each with its own tutorial step
- Shop with coins, gems and power-up charges, daily login rewards, settings and a first-run tutorial
- Optional real ads (Unity LevelPlay) and in-app purchases (Unity IAP 5). They switch on when you install the packages. In the Editor you get pretend ads and a fake store, so you can test with no accounts.
- Mobile-optimized UI built from prefabs

**No-code editor tools** (Match Them All menu)
- Template Editor: make and edit levels, goals, timer, rewards and tutorial steps
- Item Manager: turn your own 3D models into items, with automatic icons
- Power-up Manager: edit the four power-ups or add your own
- Shop Manager, Sound Manager and Player Data windows
- Set Up Project: one click does the first-time project setup after you import

**Documentation**
An illustrated user guide with a page for every tool, gameplay GIFs and annotated screenshots, plus developer docs (architecture overview and API reference).

**Requirements**
- Unity 6000.0 LTS (Unity 6) with the Universal Render Pipeline
- Git installed on your computer
- PrimeTween (free on the Asset Store) and ZLinq (free, from GitHub). They are not included.
- Unity packages: Addressables, Input System, Unity UI (the guide lists the steps)

**Content and licence**
All art, audio, models and VFX are original, CC0 or OFL, with notices in `THIRD_PARTY_NOTICES.txt`.
