# Changelog

## v1.0.0 - 2026-11-19 (Initial release)

### Game
- Complete match-3D gameplay: tap items into a tray, merge three of a kind, finish the goal cards before the timer runs out
- 4 power-ups: Fan, Freeze, Spring, Vacuum
- Stars and coin rewards per level, level select saga map
- Daily rewards, shop with coins and gems, power-up charges, settings and audio
- Tutorial steps, including one for each power-up on its unlock level
- Optional real ads (LevelPlay) and real-money purchases (Unity IAP 5). They switch on when you install their packages. The Editor uses pretend ads and a fake store.
- Mobile-optimized UI

### Editor tools (no code needed)
- **Match Them All ▸ Set Up Project**: one click does the first-time setup after importing (TextMesh Pro essentials, render pipeline, input handling, layers, level registration, build scenes). Safe to run twice.
- Template Editor: make and edit levels, goals, timer, rewards and tutorials
- Item Manager: turn your 3D models into items, with automatic icons and tray placement
- Shop Manager, Sound Manager, Power-up Manager (add your own power-ups) and Player Data windows
