# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-07

### Added
- Initial release of Match Them All - Complete Game Template
- Full match-3 gameplay system with merge mechanics
- Level editor for creating custom levels without coding
- Power-up system with 4 types: Fan, Freeze, Spring, Vacuum
- Shop and currency system (Gems, Daily Rewards, Watch Ads)
- Save system for player progress
- Mobile-ready UI with touch controls
- 6 example levels
- VFX effects for matches and power-ups
- Tutorial system for onboarding players

### Features
- Drag-and-drop level creation
- Visual level preview
- Auto-generation of matching patterns
- Configurable difficulty settings
- Customizable item types
- Multiple goal types (Moves, Time, Score, Objectives)
- Combo system with multipliers
- Win/Lose states with replay options
- Settings panel (Sound, Music, Vibration)

### Technical
- Clean architecture using EventBus pattern
- Object pooling for performance
- Assembly Definition files for code organization
- XML documentation for public APIs
