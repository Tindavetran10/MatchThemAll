# 5. Ads and In-App Purchases

Out of the box, the template uses **pretend ads** (a short fake video) and the coin shop, so you can test
everything without any accounts. Real ads and real-money products switch on by themselves when you install their
packages. **No code changes are needed.**

| Install (*Window ▸ Package Manager ▸ Unity Registry*) | Switches on |
|---|---|
| **Ads Mediation** (LevelPlay 9.5 or newer) | Real rewarded and in-between-level ads |
| **In-App Purchasing** (Unity IAP 5 or newer) | Real-money shop products, and Restore Purchases on iOS |

| Page | What it covers |
|---|---|
| [Ads](Ads.md) | Ad keys, where ads appear, how often, privacy, and testing |
| [In-App Purchases](In-App-Purchases.md) | Selling a shop product for real money |

> The complete technical setup (store accounts, Android permissions, iOS settings) is in
> `Documentation/MONETIZATION_SETUP.md`. It's technical setup, not legal advice.
