# Requirements

Install these before you open the template.

| What | Version | How to get it |
|---|---|---|
| **Unity** | **6000.0 LTS** (Unity 6) | Unity Hub ▸ Installs ▸ Install Editor |
| **PrimeTween** | 1.x | Free on the Asset Store. **Import it before the template.** |
| **ZLinq** | latest | *Window ▸ Package Manager ▸ + ▸ Add package from git URL*, then paste: `https://github.com/Cysharp/ZLinq.git?path=src/ZLinq.Unity/Assets/ZLinq.Unity` |
| Universal Render Pipeline, Input System, Addressables | | Installed with the project. Nothing to do. |
| NaughtyAttributes | | Included in `ThirdParty/NaughtyAttributes`. Nothing to do. |
| Ads Mediation (LevelPlay), In-App Purchasing | optional | Only for real ads and real-money products. See [Ads and In-App Purchases](../05-Ads-and-In-App-Purchases/README.md). |

> **Use Unity 6000.0.** Opening the project in a newer Unity version upgrades some files. If you then go back to
> 6000.0, the build can fail.
