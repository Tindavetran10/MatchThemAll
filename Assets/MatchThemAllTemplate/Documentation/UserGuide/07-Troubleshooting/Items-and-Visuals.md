# Items and Visuals

| Problem | Fix |
|---|---|
| An item loses its colours when tapped | Its model uses more than one material. Combine them into one material. |
| An item sits tilted or off-centre in the tray | Use the Item Manager's [Dock Placement](../03-Editor-Tools/Item-Manager/Dock-Placement.md). |
| The buttons look stretched or squashed in Play mode | The Game view is on *Free Aspect*. Pick a portrait size, or use the Device Simulator ([First Run](../01-Getting-Started/First-Run.md)). |
| A button colour looks fine in the Editor but darker in the game | On that button, set **Normal Color** (under *Button ▸ Color Tint*) back to white, and colour the image instead. |
